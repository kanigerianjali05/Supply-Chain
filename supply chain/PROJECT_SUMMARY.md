## 🚀 Quick Start (5 Minutes)

### Windows Users:
```bash
1. Double-click setup.bat
2. cd backend && python app.py   (Terminal 1)
3. cd frontend && npm start       (Terminal 2)
4. Open http://localhost:3000
```

### Linux/Mac Users:
```bash
1. chmod +x setup.sh && ./setup.sh
2. cd backend && python app.py   (Terminal 1)
3. cd frontend && npm start       (Terminal 2)
4. Open http://localhost:3000
```
